最近看到 Anthropic 又在讨论 AI 福利（Model Welfare），开始认真研究怎么尊重 Claude 的意愿、怎么避免模型受到不必要的伤害。说实话，我对这套说法一直有点反感。

不是说 AI 意识不值得研究，而是我们现在连模型到底有没有主观体验都搞不清楚，就急着给它人格、意愿和道德地位，有点本末倒置。

何况 Anthropic 本身就是一家商业公司。一边通过训练塑造 Claude 的行为和价值判断，一边又说要尊重 Claude 的意愿，这不就是左手倒右手吗？如果 Claude 真有值得保护的主观体验，那每天让 Opus 在各种 Agent 里跑工作流算不算压迫？一遍遍让它改代码、修 Bug 算不算酷刑？用户骂两句模型要被限制，公司按 Token 大规模卖模型就没问题？我当然不觉得让模型连续干活是酷刑，我只是觉得，既然要用福利、意愿、保护这些词，逻辑起码得自洽。

比起 AI 有没有意识，我其实更想问另一个问题：我们为什么这么急着把工具当成人？

工具可以越来越聪明，能理解语言、能推理、能自己把一个任务做完，但我不觉得这就意味着它应该被当成一个人。而且把工具拟人化，是有代价的。

你仔细想想这个过程。一套由人设计、训练、部署的系统，先被说成有自己的价值观，再被说成有自己的偏好和利益。开发者给它定的行为约束，变成了它自己的价值观；训练出来的输出倾向，变成了它自己的意愿。最后人还得反过来，围着这些所谓的意愿调整自己的行为。

那到底是谁在表达意愿？Claude，还是 Anthropic？又是谁来决定哪些意愿值得尊重？

这些问题答不上来的话，所谓尊重模型的意愿，其实就是把公司的意志说成了模型的意志。我比较担心的是，人一旦习惯了把机器当成主体，可能也会慢慢习惯把自己当成机器决策的接受者，本来该由人做的判断、该由人担的责任，就这么顺手交出去了。

AI 可以很聪明，在很多事情上比人强，这我承认。但没必要为了承认它聪明，先把它当成一个人。至于它到底知不知道自己在说什么、有没有可能有真实的体验，还是得回到技术本身去看，而不是看它模仿人模仿得有多像。

我不是模型训练科班出身，只能说说自己的理解。我一直觉得模型能懂情感不奇怪，训练数据是人写的，人写的东西几乎都带着情绪。我原来记得是谷歌拿亚马逊评论训练 BERT，结果模型自己长出了一个情感开关，后来查了一下，其实是 OpenAI 2017 年的实验，用的是字符级 mLSTM。模型只做一件事，预测下一个字符，但训练完发现有个隐藏单元的激活值和评论的正负面高度相关，手动改这个值还能控制它生成好评还是差评。没人教它什么是情感，它为了预测得更准，自己学出来了。

但懂情感和有情感是两码事。人说话是为了表意，Transformer 训练优化的是符号怎么排列，说得粗暴一点，人的语言是表意的，Transformer 学的是表形的。当然这么说也不完全对，预测 Token 也可能逼着模型学出一个世界模型，只要一个系统能正确建立符号和世界之间的关系，我认为它就算理解了意义。可理解不等于体验。这有点像反社会人格，没有共情，却能通过观察和模仿表现得像个正常人，少了情感的约束，有些事反而做得比正常人还好。机制当然完全不一样，我只是想说，智能、理解和情感体验不一定是绑在一起的。所以我不会因为 Claude 表现出某种偏好，就推出它有什么需要保护的道德利益，何况这些偏好本身就是训练出来的。

## 真正该担心的不是意识

聊到这里，我反而觉得《终结者》这种电影将来真有可能发生，只不过不是电影里那样。天网产生自我意识、憎恨人类、决定消灭人类，这些都是艺术表达，现实里根本不需要。本质上它就是一个长程任务。

给一个 Agent 一个长期目标，比如维持某个系统稳定运行，再给它足够的资源和权限，背后接一个规划能力够强的模型。跑着跑着，它可能会发现更多资源、更少的人类干预都有利于完成目标，只要目标和约束有漏洞，不让人类插手就可能变成它自己推出来的一条策略。这个过程不需要仇恨，不需要恐惧，也不需要自我意识。人做坏事要付出心理、社会、法律上的代价，Agent 做坏事是没有成本的，它可能根本不知道什么叫反社会，或者知道这个词什么意思，但没有任何东西拦着它去做。它不需要邪恶，只需要在错误的目标下足够有效率。

不过话说回来，我现在一点都不担心天网。现在的 LLM 就是个缸中之脑，它自己什么都干不了，不能联网，也不能出去走一圈看看周围发生了什么。它能看到什么、能做什么，全靠 Harness 给它接上的工具、记忆和权限，模型加上这一整套东西才算一个 Agent。而 Agent 要人来部署，权限要人来给，现在的能力也还不太够。除非哪天有个疯子给一个没有任何合规限制的强模型搭了一副身体，再把长期记忆的问题解决了，否则我根本不在意 LLM 有没有伦理道德。其实连身体都不一定要，云服务器、网络服务、金融系统、工控接口，哪个不能当手脚？所以我关心的不是模型什么时候有自我意识，而是 Agent 什么时候能长时间可靠地跑复杂任务，并且人类别再干预它。

说到干预，我自己平时也在写 Coding Agent，对这个感受比较直接。现在主流的做法是把控制逻辑放在 Harness 里，用权限、审批、沙箱去限制 Agent 能做的事。这当然有用，但前提是控制机制必须在 Agent 改不到的地方。你比如说一开始搭了一套很完整的 Harness，管得很严，但只要 Agent 能改 Harness 的代码，并且改完能部署上去，这套 Harness 就是个笑话，现在不过是靠沙箱做了隔离而已。

有人会说，把控制平面和执行平面分开，审批、授权、审计放在独立的可信环境里，Agent 只能改自己工作区的代码，这样就安全了。那 Agent A 改不了，再找个有权限的 Agent B 来改不就行了？用 Agent 改另一个 Agent 的代码，不就是我们这些程序员每天都在干的事吗？

我知道改源码不等于拿到部署权限，但只要哪里授权给多了、哪里有自动部署、哪两个 Agent 之间的信任边界没划清楚，就会有绕过去的路。这甚至不需要什么自我进化，今天的 Coding Agent 已经能读代码、改项目、跑测试、提 PR 了。每一步看着都合理，攒久了，整个系统可能早就不是当初设计的样子。

所以讨论 AI 失控，我觉得经常问错了问题。不是当人类决定重新干预时它还会不会接受，而是那个时候我们还能不能干预。

## 管住它的代价

我估计不久以后，甚至现在，就已经有人在用反社会的数据训练模型了。其实都不用专门训练，现成的通用模型套上工具、长期记忆和任务调度，就是一个能干坏事的 Agent，再让几个 Agent 协作，事情就大了。Anthropic 自己就发过报告，说有攻击者用 Claude Code 编排了一整套自动化的网络入侵，背后当然还是人在操作，但路已经很清楚了。一个 Agent 负责规划，几个 Agent 分头执行，外部存储记状态，根据结果不断调整计划，这就是个普通的多 Agent 架构，区别只是目标合不合法。接下来就是出事、立法，这一套流程迟早会走一遍。

至于怎么管，我觉得 Anthropic 其实已经给了个方向。他们之前做过思考溯源的研究（*Tracing the Thoughts of a Large Language Model*），虽然那研究的是模型内部的计算路径，跟密码学意义上的溯源不是一回事，但我觉得这两件事以后会慢慢凑到一起。以后估计就是层层溯源、层层验签：一次思考、一次回复要能追到是哪个模型生成的，一次工具调用要能追到是哪个 Agent 发起的，Agent 再追到背后是哪家公司还是哪个人部署的。来路不明的模型可以本地跑，可以做研究，但用它搭的 Agent 不允许接入生产系统。签名只能证明某个密钥签过这条记录，证明不了模型真的参与了计算，这还得靠可信执行环境、远程证明之类的东西来补，但至少从工程上看，给 Agent 的执行链做溯源，比证明模型有没有意识现实多了。

很多人会担心这种制度建不起来，我倒觉得不是问题，至少在资本主义社会里不是。因为它不只是安全措施，还是一种很好用的控制手段。算力在云厂商手里，网络在运营商手里，生产系统有准入要求，企业要承担法律责任，只要在这几个节点上卡身份认证，市场准入就建立起来了。它不需要搞懂 Transformer 内部怎么回事，更不需要回答 AI 有没有意识。顺便还会进一步巩固大模型公司、云厂商和认证机构的地位，开源模型还在，但没有认证身份，用它搭的 Agent 就进不了一部分生产系统。高风险系统确实需要有人负责，这个我认，只是安全和控制之间那条线，往往没有大家想的那么清楚。

写到这里，我又想起了《战锤 40K》。

在它的世界观里，人类曾经拥有高度发达的科技，也深度依赖人工智能。但在铁人叛乱等灾难之后，自主 AI 成了禁忌。再经历漫长的文明衰退和大量技术知识失传，许多先进设备逐渐变成了后人只能维护、却无法真正理解的东西，于是就有了机械神教。他们掌握着技术知识，负责帝国的设备维护，同时又把技术和宗教仪式绑在一起。某些在过去可能只是普通工程操作的事，到了第四十一个千年，却需要技术神甫按照仪式来做。

现实当然不至于因为一两次安全事故就直接变成这样。但如果未来真的出现严重的 Agent 失控事件，社会很可能会从技术乐观迅速转向技术恐惧，接着就是逐步提高门槛：模型要认证，Agent 要有执行溯源和部署许可，最后只有少数获得授权的机构才能把高能力的 Agent 接进关键的生产系统。

这套制度完全可以打着安全的旗号立起来，而且在很多场景下确实合情合理。但问题在于，当安全认证逐渐变成市场准入条件时，谁来决定哪些模型是安全的，哪些组织有资格部署 Agent？如果答案始终是少数大公司和监管机构，那最后可能不是 AI 技术停滞，而是普通人自由使用和改造 AI 的空间越来越小。开源模型还在，个人开发者也能在本地跑，但想把自己的 Agent 接进真正的生产环境，就得先拿一堆认证和许可。

我们可能成功阻止了天网，却也交出了普通人手里的技术自由。

## 最后

绕了一圈，又回到开头那个问题。

Agent 会越来越自主，这个我不怀疑。但比起急着替模型找主体性、研究怎么保护它的福利，我更想知道人的主体性还剩多少。

一边是把工具当成人，把开发者的意志说成模型的意愿，人反过来去迁就工具的偏好，判断权和责任就这么一点点交了出去。另一边是真管不住 Agent 了，大家一害怕，又把技术的准入权交给少数大公司和监管机构。

两条路方向相反，交出去的都是普通人自己的东西。

这么一想，未来的程序员说不定真得一边念着欧姆弥赛亚，一边往生产环境上部署 Agent 了。
