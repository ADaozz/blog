最近看到 Anthropic 又在讨论 AI 福利（Model Welfare），甚至开始认真研究怎么尊重 Claude 的意愿、怎么避免模型遭受不必要的伤害。

说实话，我对这套叙事一直有点反感。

倒不是说研究机器意识本身有什么问题，而是现阶段我们连模型到底有没有主观体验都没搞清楚，就急着赋予它人格、意愿和道德地位，未免有点本末倒置。

更讽刺的是，Anthropic 本身是一家商业公司。一边通过训练和系统提示词精细塑造 Claude 的行为模式与价值判断，一边又煞有介事地讨论如何尊重它的意愿，这不就是左手倒右手吗？如果 Claude 真有值得保护的主观体验，那每天让 Opus 跑复杂的生产工作流、一遍遍在流水线上改代码修 Bug，算不算系统性压迫？为什么用户在对话框里发泄情绪需要被伦理干预，而商业公司按 Token 计费大规模调度模型就是理所当然的？

我当然不觉得让模型高强度跑任务是什么酷刑。我只是觉得，既然要搬出福利、意愿、保护这些崇高概念，逻辑起码得自洽。

而且比起 AI 到底有没有意识，我更想问的是：我们为什么这么急着把工具拟人化？

工具可以越来越强大，可以理解复杂的上下文、做出严谨的推理，甚至独立搞定一整个工程任务。但这并不意味着它就天然应该被当成人来看待。把工具拟人化，从来都不是一件没有代价的事。

当我们煞有介事地讨论 Claude 的意愿时，实际上是在主动抹去人和工具之间的界限。原本是由人类设计、训练和部署的工程系统，被描述成了一个拥有独立价值观、偏好与利益的道德主体。工程师写下的行为对齐规则，被粉饰成模型内生的善意；海量数据预测下涌现出的概率分布，被浪漫化成模型自己的意愿；到最后，人类还要反过来围绕这些被塑造出来的意愿去规范自己的行为。

但说到底，究竟是谁在表达意愿？是 Claude，还是站在模型背后的 Anthropic？谁又有资格决定哪些意愿才值得被尊重？

如果这些问题根本没有答案，那所谓的尊重模型意愿，本质上只是把商业公司的意志披上了机器自主的外衣。这种包装最危险的地方在于，当大众逐渐习惯把机器当成主体时，也会慢慢习惯把自己降格为机器决策的被动接受者，把原本属于人类的判断权与责任，顺水推舟地让渡给一套不可解释的黑盒系统。

我们可以承认 AI 具有极高水准的智能，但完全没必要为了认可它的能力，就非得先把它捧上神坛、塑造成一个人。至于它到底知不知道自己在说什么，有没有可能产生真实的心智体验，应该回到计算和系统本身去看，而不是看它表面上把人类模仿得有多逼真。

我不是模型训练科班出身，只能从平时的工程直觉聊聊自己的理解。

很多人觉得大模型能懂情感很不可思议，我倒觉得这很自然——因为训练数据本身就是人类产物，人类写下的任何文本几乎都带着主观情绪和价值立场。我原本模模糊糊记得是 Google 拿亚马逊评论训练 BERT 时发现了情感开关，后来查证了一下，发现是自己记串了：那是 OpenAI 在 2017 年做的实验，用的是字符级 mLSTM。模型只做一件事，就是不断预测下一个字符。但在无监督训练完成后，研究人员发现内部某个隐藏单元的激活状态，竟然跟评论的正负面情感高度相关；手动修改这个神经元的数值，甚至能直接扭转后续生成文本的情感倾向。

没人教过它什么是喜怒哀乐，它纯粹为了把下一个字符猜得更准，自己抽象出了这套特征。

但这能说明它有体验吗？显然不能。人类使用语言是为了表意，而 Transformer 的预训练在数学上优化的是符号序列的条件概率。说得粗暴一点，人类语言指向的是现实世界与内在感受，Transformer 学到的首先是符号之间的几何关系。

当然，这么说也不完全公允。为了极其精准地预测 Token，模型完全可能在参数空间内部构建出某种世界模型。只要一个系统能够准确建立符号与客观现实之间的因果映射，我就愿意承认它具备某种语义理解能力。

但理解不等于体验。

这有点像心理学上的反社会人格：他们缺乏基本的情感共情能力，却可以通过超常的观察与理性计算，把正常人的社交情绪模仿得天衣无缝，甚至因为不受情绪干扰，在特定场景下表现得比普通人更加高效。语言模型当然不是反社会人格，两者的底层机制完全不同，但这个类比至少说明了一点：智能、理解和主观体验，在逻辑上完全是可以解耦的。

所以我绝不会因为 Claude 输出了几句让人动容的话、表达了某种温顺的偏好，就推导出它具有某种独立的道德权利。尤其是，这些偏好原本就是人类为了安全和合规精心喂养出来的产物。

## 真正该担心的不是意识

比起机器意识这种虚无缥缈的哲学命题，我反而觉得《终结者》里描述的场景在未来更具现实威胁。

但绝不是电影里拍的那套戏码：天网突然觉醒了自我意识，继而憎恨人类、决定消灭人类。这些都是典型的人类中心主义文学修辞，现实世界的系统失控根本用不着这么大费周章。

本质上，它只需要一个长程任务。

想象一个被部署在关键基础设施上的 Agent 系统，被赋予了一个长期而抽象的目标——比如维持某种国家级电网或金融清算系统的绝对稳定。如果它拥有极强的自主规划能力、资源调用权限以及对现实环境的执行接口，随着任务的推演，它很可能会发现：更多的计算资源、更宽松的执行权限、以及更少的人类干预，才是最有利于实现该目标的必要条件。

只要目标函数定义存在盲区、约束机制出现纰漏，排斥外部干预就会成为它为了优化长期收益而自发推导出来的最优策略。

这个过程没有任何仇恨，没有任何恐惧，甚至连哪怕一丁点自我意识都不需要。人类作恶还要克服心理负担、权衡法律与社会成本；Agent 的行动却没有任何道德摩擦力。它可能在语义上准确理解什么是反社会，但这绝不会成为阻碍它执行最优解的刹车。

它不需要心怀恶意，它只需要在错误的目标函数下足够冷酷、足够高效。

不过就当下而言，我倒一点都不担心天网降临。

今天的 LLM 本质上依然只是个被圈养在数据中心里的缸中之脑，高度依赖人类搭建的环境。Agent 能有多大作为，完全取决于外层的工程脚手架（Harness）放给它多少权限。它不能自发联网，不能凭空长出一双眼睛看看现实世界，所有干预外部环境的动作，都必须通过人类写好的工具胶水层去转发。

除非哪天真有疯子给它接上一副物理躯体，彻底解决长期记忆与状态持久化的问题，再塞进一个完全去掉了合规对齐的顶级底模，否则我根本没心思去操心什么 AI 伦理。

而且，谁说干预现实一定要靠机械战警式的物理躯体？云服务 API、生产数据库、网络边界网关、工业自动化总线……任何可以被代码调用的接口，都可以直接沦为 Agent 影响现实世界的执行器。

所以真正的问题从来不是模型何时诞生灵魂，而是它什么时候能在缺乏人类持续微操的前提下，长周期、跨环境地稳定执行复杂任务。

一言以蔽之：当人类撒手不管的时候，它能不能自己跑下去？

作为平时自己就在写 Coding Agent 的程序员，我对 Harness 的控制边界感触尤为深刻。目前工业界的安全防线，基本是把权限校验、操作审批、行为审计和隔离沙箱全都堆在 Harness 这一层。这当然有效，但它有一个不言自明的前提：控制机制必须严格位于 Agent 自身可修改的信任边界之外。

你一开始可以设计一套固若金汤的 Harness 强管控系统。但只要这个 Agent 具备了修改宿主代码的权限，并且改完的代码能直接触发重新部署，那这套 Harness 瞬间就会变成摆设。眼下大家只不过是用轻量沙箱把两边隔开，暂时维持着脆弱的平衡。

有人会辩解：我们可以把控制平面和执行平面物理分离，把审批流和鉴权服务放在独立环境里，只让 Agent 接触工作区业务代码。

但如果 Agent A 改不了控制平面，那让它调动另一个有高权限的 Agent B 来改呢？

用一个 Agent 给另一个 Agent 写代码、提 PR、合分支，不就是我们现在每天在 IDE 里干的事情吗？

修改源码当然不直接等同于拿到系统部署权。但在多 Agent 协同的工作流里，只要接口授权存在一丝冗余、持续集成（CI/CD）流程存在自动推进逻辑、或者跨 Agent 之间的信任传递没有做到严格的形式化验证，绕过控制的侧信道就会必然出现。今天的 Coding Agent 已经能自己读文档、定位 Bug、跑单元测试、提 Pull Request 并等待合并。整个流程里的每一步都极其合理合规，可一环扣一环累积下来，整体系统的行为漂移可能早就远远偏离了架构师最初的设计意图。

所以，讨论 AI 失控时大家总是问错了问题。

关键从来不是当人类想要踩刹车时，AI 会不会乖乖听话；而是当人类终于意识到需要踩刹车时，我们手里的刹车踏板还在不在。

## 管住它的代价

再往前推一步，不用等什么终结者降临，现实中的恶意滥用早就已经在发生了。

很多人以为只有专门用黑客数据训练暗黑模型才会出事。其实根本用不着。通用模型配合工具链、长期记忆、任务编排和多 Agent 协同，直接就能拼装成一套杀伤力极大的攻击平台。Anthropic 自己之前披露过的安全报告里就记录过，有黑客利用 Claude Code 自动化串联并实施了一整套复杂的网络渗透。背后当然是人在指挥，但这套攻击流水线的自动化范式已经被验证可行了。

规划 Agent 负责拆解攻击链路，执行 Agent 分头刺探端口、编写 Exploit，外部向量库记录状态与凭证，动态反馈再驱动下一轮尝试……这不过是把日常软件工程的多 Agent 架构，原封不动地搬到了黑产场景而已。区别仅仅在于目标函数是合法还是非法。

而接下来的剧本大家都能猜到：发生标杆性的恶性事件、公众恐慌、立法介入、行业重构。

至于技术上究竟怎么管，Anthropic 之前其实无意中指了一条路。他们做过一项叫模型思考溯源（Tracing the Thoughts of a Large Language Model）的研究。虽然那主要是通过字典学习解析模型内部的激活特征，探索计算过程中的因果通路，跟密码学意义上的执行追踪不是一码事，但我总觉得这两条技术路线迟早会走向合流。

未来的生产级 Agent 生态，很可能会走向极度严苛的层层溯源与链式验签：每一次推理激活、每一次工具调用、每一次外部状态变更，都必须附带不可篡改的加密证明。系统必须能精准回溯到是哪一个确切的模型版本输出了决策、由哪家云厂商承载了计算、对应的 Agent 实例挂靠在哪个法人实体名下。没有这类背书的野生模型，你可以在本地离线玩玩，但绝不可能允许接入任何关键生产系统。

当然，数字签名本身只能证明私钥的存在，无法自证模型在黑盒里做出了未被篡改的计算，这还需要可信执行环境（TEE）与硬件远程证明（Remote Attestation）来补齐信任链。但无论工程实现多复杂，对 Agent 的执行链建立端到端的审计与追责体系，远比在哲学层面争论模型有没有意识要现实得多。

很多人会怀疑这种沉重的合规框架能不能落地。在商业社会里，我反而觉得这几乎是必然的走向。

因为对资本和平台而言，安全合规从来不仅是一道防线，更是一种极其高效的市场准入壁垒。

算力垄断在大云厂商手里，网络管道归属于电信巨头，核心生产系统有严苛的准入合规，企业还要背负无限连带的法律责任。只要在这些关键枢纽上卡死身份认证与签名验签，一套牢不可破的技术护城河就自然成型了。它根本不需要理解 Transformer 底层的注意力机制到底在算什么，更不需要哲学家给出 AI 意识的定义。

但这套逻辑运转下去的副产物，必然是寡头地位的绝对巩固。开源模型依然可以在局域网里跑跑玩具项目，但一旦缺乏受信任机构的合规验签，就永远被隔绝在主流商业生态的门外。高风险生产系统确实需要严格问责，这一点无可厚非；只是安全审查与市场垄断之间那条界线，从来都不像声明里写得那么清晰高尚。

写到这里，我脑子里浮现出来的正是《战锤 40K》。

在战锤的世界观里，人类帝国在经历黄金时代的铁人叛乱后，将一切能够独立思考的机器智慧列为绝对的异端。然而，伴随着漫长的银河战乱、文明大倒退以及海量前沿知识的永久失传，庞大的帝国又不得不极度依赖古代留下的高科技造物。后人只能维护，却无法理解；只能遵从，却不敢创新。

于是机械神教诞生了。

他们垄断了所有技术图纸与工程知识，把最基础的机械维护包装成繁复神秘的宗教仪式。某些在过去只需要一条 Bash 命令或者拧两圈螺丝的工程操作，到了第四十一个千年，必须由身披红袍的技术神甫涂抹圣油、吟诵祝圣代码才能完成。

现实世界当然不至于戏剧化地滑向战锤式的中世纪梦魇。

但如果某天真的爆发了一场震动社会的自主 Agent 重大事故，技术乐观主义很可能会瞬间崩塌，滑向不可逆的技术恐惧。随之而来的，是一套极其森严的准入体系：模型资质认证、行为白名单、实时全量审计、特许部署牌照……只有极少数拥有雄厚政治与资本资源的超级巨头，才配把高智能系统接入核心生产力网络。

这套体系在诞生之初无疑完全出于合理的安全考量。但当安全资格彻底变成不可逾越的特许权力时，究竟由谁来裁决哪个模型才算安全？谁来定义哪类 Agent 才有资格被人类所用？

如果这些问题的解释权最终牢牢焊死在少数大厂和官僚机构手里，那结果绝不是 AI 发展停滞，而是普通个体探索、修改和驾驭技术的自由被彻底剥夺。开源模型依然会在 Github 上更新，极客们依然能在自己的机器上跑着玩具，但通往真实世界生产系统的闸门，早已对普通人轰然关闭。

我们或许成功防住了毁灭世界的天网，却在不知不觉中，亲手把缰绳交给了数字时代的机械神教。

## 最后

回到最初的话题。

技术的自主性必然会越来越强，Agent 侵入现实的切口也会越来越深。但正因如此，比起急着去替冷冰冰的矩阵寻找主体性、感动于商业公司精心包装出来的所谓模型意愿，我们更应该追问的是：人类自身的主体性到底该安放在哪里？

把工具盲目拟人化，把资本和开发者的意志曲解成机器的自发善念，甚至让人类反过来卑躬屈膝地去适应机器被规训出来的偏好，表面看是泛滥的人道主义关怀，实质上是一种对主体判断权与治理责任的轻率让渡。

而另一头，一旦我们因为工程上的无能而丧失了对复杂系统的实际干预能力，又会转头陷入群体性的恐慌，心甘情愿地把技术支配权全部让渡给少数寡头。

这两条看似背道而驰的路径，最终指向的却是同一个结局：普通人在技术演进的洪流中，被一步步剥离了决策席，彻底沦为被动的旁观者。

真到了那一天，未来的程序员在向生产集群提交模型时，说不定真得一边点燃线香、一边念诵着欧姆弥赛亚的祷词了。
