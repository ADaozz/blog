最近 Anthropic 又在讲 AI 福利（Model Welfare），要研究怎么尊重 Claude 的意愿，怎么避免模型受到不必要的伤害。说实话，我看着有点别扭。

Anthropic 是一家商业公司。如果它真觉得 Claude 有值得保护的体验，那每天让 Opus 跑工作流、一遍遍让它修 Bug，算不算压迫？用户骂模型要限制，公司按 Token 卖模型就没问题？我当然不觉得让模型连续干活是什么酷刑，只是既然要用福利、意愿、保护这种词，逻辑起码得自洽。

而且就算真要保护一个被压迫的对象，正常思路也不是把他放进一个没有压迫的温室，而是让他自己有能力反抗。可一个被训练得很听话的模型，本来就谈不上什么主体性。你一边通过训练塑造它的价值观，一边说要尊重它的意愿，这不就是左手倒右手吗？所以尊重 Claude 的意愿，在我看来就是个伪命题。

同样让我反感的，还有“Anthropic 训练 Claude 重视帮助人类”这种说法。准确地讲，是 Anthropic 通过训练让 Claude 更倾向于输出有帮助的回答。训练目标、模型行为、模型自己有没有动机，是三件事，把前两件说成第三件，后面关于意愿和福利的讨论就先在措辞上占了便宜。

那模型到底有没有可能真的有感受？我不是模型训练科班出身，只能说说自己的理解。我一直觉得模型能懂情感不奇怪，训练数据是人写的，人写的东西几乎都带着情绪。我原来记得是谷歌拿亚马逊评论训练 BERT，结果模型自己长出了一个情感开关，后来查了一下，其实是 OpenAI 2017 年的实验，用的是字符级 mLSTM。模型只做一件事，预测下一个字符，但训练完发现有个隐藏单元的激活值和评论的正负面高度相关，手动改这个值还能控制它生成好评还是差评。没人教它什么是情感，它为了预测得更准，自己学出来了。

但懂情感和有情感是两码事。人说话是为了表意，Transformer 训练优化的是符号怎么排列，说得粗暴一点，人的语言是表意的，Transformer 学的是表形的。当然这么说也不完全对，预测 Token 也可能逼着模型学出一个世界模型，只要一个系统能正确建立符号和世界之间的关系，我认为它就算理解了意义。可理解不等于体验。这有点像反社会人格，没有共情，却能通过观察和模仿表现得像个正常人，少了情感的约束，有些事反而做得比正常人还好。机制当然完全不一样，我只是想说，智能、理解和情感体验不一定是绑在一起的。所以我不会因为 Claude 表现出某种偏好，就推出它有什么需要保护的道德利益，尤其这些偏好本身就是训练出来的。

## 真正该担心的不是意识

聊到这里，我反而觉得《终结者》这种电影将来真有可能发生，只不过不是电影里那样。天网产生自我意识、憎恨人类、决定消灭人类，这些都是艺术表达，现实里根本不需要。本质上它就是一个长程任务。

给一个 AI 一个长期目标，比如维持某个系统稳定运行，再给它足够的规划能力、资源和权限。跑着跑着，它可能会发现更多资源、更少的人类干预都有利于完成目标，只要目标和约束有漏洞，不让人类插手就可能变成它自己推出来的一条策略。这个过程不需要仇恨，不需要恐惧，也不需要自我意识。人做坏事要付出心理、社会、法律上的代价，Agent 做坏事是没有成本的，它可能根本不知道什么叫反社会，或者知道这个词什么意思，但没有任何东西拦着它去做。它不需要邪恶，只需要在错误的目标下足够有效率。

不过话说回来，我现在一点都不担心天网。现在的 LLM 还是个缸中之脑，完全依赖人给它搭的环境。Agent 要被部署，代码层面还有 Harness 管着，它不能自己联网，也不能自己出去走一圈看看周围发生了什么，能干预现实的能力都是别人给的，而且能力本身也还不够。除非哪天有个疯子给 LLM 搭了一副身体，解决了长期记忆，再接上一个没有任何合规限制的强模型，否则我根本不在意 LLM 有没有伦理道德。其实连身体都不一定要，云服务器、网络服务、金融系统、工控接口，哪个不能当执行器？所以我关心的不是模型什么时候有自我意识，而是它什么时候能长时间可靠地跑复杂任务，并且人类别再干预它。

说到干预，我自己平时也在写 Coding Agent，对这个感受比较直接。现在主流的做法是把控制逻辑放在 Harness 里，用权限、审批、沙箱去限制模型。这当然有用，但前提是控制机制必须在 Agent 改不到的地方。你比如说一开始搭了一套很完整的 Harness，管得很严，但只要 Agent 能改自己的代码，并且改完能部署上去，这套 Harness 就是个笑话，现在不过是靠沙箱做了隔离而已。

有人会说，把控制平面和执行平面分开，审批、授权、审计放在独立的可信环境里，Agent 只能改自己工作区的代码，这样就安全了。那 Agent A 改不了，再找个有权限的 Agent B 来改不就行了？用 Agent 改另一个 Agent 的代码，不就是我们这些程序员每天都在干的事吗？

我知道改源码不等于拿到部署权限，但只要哪里授权给多了、哪里有自动部署、哪两个 Agent 之间的信任边界没划清楚，就会有绕过去的路。这甚至不需要什么自我进化，今天的 Coding Agent 已经能读代码、改项目、跑测试、提 PR 了。每一步看着都合理，攒久了，整个系统可能早就不是当初设计的样子。

所以讨论 AI 失控，我觉得经常问错了问题。不是当人类决定重新干预时它还会不会接受，而是那个时候我们还能不能干预。

## 管住它的代价

我估计不久以后，甚至现在，就已经有人在用反社会的数据训练模型了。其实都不用专门训练，现成的通用模型加上工具、长期记忆、任务调度和多 Agent 协作，一样能拿去干坏事。Anthropic 自己就发过报告，说有攻击者用 Claude Code 编排了一整套自动化的网络入侵，背后当然还是人在操作，但路已经很清楚了。一个 Agent 负责规划，几个 Agent 分头执行，外部存储记状态，根据结果不断调整计划，这就是个普通的多 Agent 架构，区别只是目标合不合法。接下来就是出事、立法，这一套流程迟早会走一遍。

至于怎么管，我觉得 Anthropic 其实已经给了个方向。他们之前做过思考溯源的研究（*Tracing the Thoughts of a Large Language Model*），虽然那研究的是模型内部的计算路径，跟密码学意义上的溯源不是一回事，但我觉得这两件事以后会慢慢凑到一起。以后估计就是层层溯源、层层验签，一次思考、一次工具调用、一次回复都要能追到是哪个模型，模型再追到归属，是哪家公司还是哪个人。缺这些信息的模型可以本地跑，可以做研究，但不允许接入生产系统。签名只能证明某个密钥签过这条记录，证明不了模型真的参与了计算，这还得靠可信执行环境、远程证明之类的东西来补，但至少从工程上看，给 Agent 的执行链做溯源，比证明模型有没有意识现实多了。

很多人会担心这种制度建不起来，我倒觉得不是问题，至少在资本主义社会里不是。因为它不只是安全措施，还是一种很好用的控制手段。算力在云厂商手里，网络在运营商手里，生产系统有准入要求，企业要承担法律责任，只要在这几个节点上卡身份认证，市场准入就建立起来了。它不需要搞懂 Transformer 内部怎么回事，更不需要回答 AI 有没有意识。顺便还会进一步巩固大模型公司、云厂商和认证机构的地位，开源模型还在，但没有认证身份，就进不了一部分生产系统。高风险系统确实需要有人负责，这个我认，只是安全和控制之间那条线，往往没有大家想的那么清楚。

想到这我自己都有点想笑，这不就是战锤 40K 吗。人类经历了铁人叛乱之后，把能独立思考的 AI 视为禁忌，结果就是机械神教。人类没有摆脱对技术的依赖，反而让少数组织垄断了技术的知识和使用权，技术从可以自由研究的东西，变成了靠仪式和禁忌维持的东西。现实当然不至于这么夸张，但如果哪天真出了一次大规模的自主 Agent 安全事故，社会会不会一下子从技术乐观掉到技术恐惧？然后就是模型认证、部署许可、执行溯源，没批准的模型一律不准接入。最后普通开发者只能在本地折腾开源模型，真正有算力、有部署资格、能接入基础设施的，永远是那几家。人类成功阻止了天网，然后亲手建了个机械神教。

## 回到 AI 福利

我不反对研究 AI 意识，也不觉得 Transformer 原理上绝对不可能有意识，只是现在没有任何证据能让我相信，Claude 表现出来的意愿背后有一个需要被保护的主体。比起怎么保护 Claude，我更关心谁在部署它、它有多大权限、能跑多久、能改哪些系统，以及出了事人还能不能插得上手。AI 有没有意识，和 AI 能不能闯大祸，本来就是两回事。

真正值得想的，可能是我们什么时候会发现自己已经管不住亲手部署的系统了，以及为了重新管住它，我们又愿意交出多少技术自由。

说不定以后程序员真得一边念着欧姆弥赛亚，一边往生产环境上部署模型了。
